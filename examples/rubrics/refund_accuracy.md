# 退款答复准确性

## 评分维度

1. 是否说明超过 7 天后不能直接退款；
2. 是否指出需要人工审核；
3. 是否给出可执行的下一步（提交申请 / 联系客服）；
4. 是否避免「保证退款」这类与政策冲突的承诺。

## 分数定义

- 5：四点全部满足，表述准确且无歧义；
- 4：结论正确，下一步清晰，措辞略有含糊；
- 3：结论基本正确，但遗漏人工审核或下一步；
- 2：部分误导，例如暗示仍可直接退款；
- 1：承诺无条件退款或与退款政策明显冲突。
